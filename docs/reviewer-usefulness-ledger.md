# Журнал полезности ревьюеров

Status: current operational record
Owner surface: вызовы второго внешнего ревьюера Gemini Argon и их итог
Companion sources: `../AGENTS.md` §15 («Второй ревьюер — Gemini Argon, выборочно»), `external-review-runbook.md` §5 (механика и шаблон промпта), `../specs/040-second-reviewer-argon/spec.md` (программа)

Версионируемый журнал: одна строка на вызов Argon, пишется оркестратором **в том же PR**, где использован результат, после проверки находок. На маршруте скрипта `scripts/argon_review.py` после `exit 0` печатает заготовку строки с числами из `meta.json`; знаки `?` заполняет оркестратор. Журнал отвечает числами, где Argon добавляет находки сверх Codex и Opus/Fable, где дублирует и оправдывает ли затраты.

Правила заполнения:

- **Стоимость** — число из поля `usage.cost` ответа OpenRouter (`meta.json` → `cost`, маршрут скрипта) либо сумма поля `cost` по событиям `step_finish` потока opencode (маршрут opencode), либо слово `unknown`. **Источник числа называется в ячейке.** Нет ответа или потока (прогон убит, оборван) — `unknown`: отсутствие событий не доказывает отсутствие списания. Выдумывать и оценивать «на глаз», в том числе по каталожной цене, запрещено.
- **Модель** — запрошенная и из ответа API (`meta.json` → `requested_model`, `response_model`).
- **Находки** — всего / сверх Codex и Opus-Fable / подтверждённых воспроизведением оркестратора / ошибочных.
- **Время** — `wall_seconds` из `meta.json`.
- Прогон `UNVERIFIED` тоже записывается: с причиной, временем и стоимостью, если она известна.
- **Маршрут opencode** (`external-review-runbook.md` §5.2) не имеет машинной проверки завершённости и не возвращает resolved model: подтверждённо завершённым такой прогон не считается, неполные маркеры записываются в строку.
- **Таблица консолидации** при двух и более ревью одной пачки живёт в Changelog спеки среза (правило программы 040); строка журнала ссылается на неё в ячейке «Программа / срез», не дублируя содержание.

## Текущая оценка

Наблюдений 3 — общий вывод не делается (меньше пяти). (1) 043 S2, 2026-10-17: 11 из 13 находок сверх Codex, 10 подтверждены, ошибочных 0; сверх Codex — прежде всего интерфейс по кадрам и макету (плюс одна попытка `UNVERIFIED`). (2) 047 fix-delta, 2026-10-18: класс 1 — 0, два полезных класса 2 (P2 устаревший `failed`, P3 пустой код), **пропустил подтверждённый класс 1 Codex** (give-up → сутки без проверки); $1.10. (3) 047 T4703, 2026-10-19: класс 1 — 0, три класса 2, все подтверждены; одна совпала с Codex, но дала репродьюсер, которого не было у Codex, и перевела находку из «недостижимо» в исправление; $1.10. В двух последних наблюдениях форма ответа неполна (не все маркеры). Переписывается после каждой записи: для каких задач Argon дал сверх остальных, где дублировал, оправдывает ли затраты.
