# Журнал полезности ревьюеров

Status: current operational record
Owner surface: вызовы второго внешнего ревьюера Gemini Argon и их итог
Companion sources: `../AGENTS.md` §15 («Второй ревьюер — Gemini Argon, выборочно»), `external-review-runbook.md` §5 (механика и шаблон промпта), `../specs/040-second-reviewer-argon/spec.md` (программа)

Версионируемый журнал: одна строка на вызов Argon, пишется оркестратором **в том же PR**, где использован результат, после проверки находок. Скрипт `scripts/argon_review.py` после `exit 0` печатает заготовку строки с числами из `meta.json`; знаки `?` заполняет оркестратор. Журнал отвечает числами, где Argon добавляет находки сверх Codex и Opus/Fable, где дублирует и оправдывает ли затраты.

Правила заполнения:

- **Стоимость** — число из поля `usage.cost` ответа OpenRouter (`meta.json` → `cost`) либо слово `unknown`. Выдумывать и оценивать «на глаз», в том числе по каталожной цене, запрещено.
- **Модель** — запрошенная и из ответа API (`meta.json` → `requested_model`, `response_model`).
- **Находки** — всего / сверх Codex и Opus-Fable / подтверждённых воспроизведением оркестратора / ошибочных.
- **Время** — `wall_seconds` из `meta.json`.
- Прогон `UNVERIFIED` тоже записывается: с причиной, временем и стоимостью, если она известна.

## Текущая оценка

Наблюдений 0 — вывод не делается. Переписывается после каждой записи: для каких задач Argon дал сверх остальных, где дублировал, оправдывает ли затраты. Пока наблюдений меньше пяти, раздел называет их число и не делает общих выводов о модели.
