Версионируемый журнал: одна строка на вызов Argon, пишется оркестратором **в том же PR**, где использован результат, после проверки находок. Скрипт `scripts/argon_review.py` (печатал заготовку строки по `meta.json`) выведен 2026-10-19 (BACKLOG 040-2, замер 54.8 с / 277 с); тег `retired/040-argon-review-script`; вернуть, если ключ OpenRouter появится в окружении сессии. Журнал отвечает числами, где Argon добавляет находки сверх Codex и Opus/Fable, где дублирует и оправдывает ли затраты.

Правила заполнения:

- **Стоимость** — число из поля `usage.cost` ответа OpenRouter (`meta.json` → `cost`, выведенный маршрут скрипта) либо сумма поля `cost` по событиям `step_finish` потока opencode (маршрут opencode), либо слово `unknown`. **Источник числа называется в ячейке.** Нет ответа или потока (прогон убит, оборван) — `unknown`: отсутствие событий не доказывает отсутствие списания. Выдумывать и оценивать «на глаз», в том числе по каталожной цене, запрещено.
- **Модель** — запрошенная и из ответа API (`meta.json` → `requested_model`, `response_model`).
- **Находки** — всего / сверх Codex и Opus-Fable / подтверждённых воспроизведением оркестратора / ошибочных.
- **Время** — `wall_seconds` из `meta.json`.
- Прогон `UNVERIFIED` тоже записывается: с причиной, временем и стоимостью, если она известна.
- **Маршрут opencode** (`external-review-runbook.md` §5.2) не имеет машинной проверки завершённости и не возвращает resolved model: подтверждённо завершённым такой прогон не считается, неполные маркеры записываются в строку.
- **Таблица консолидации** при двух и более ревью одной пачки живёт в Changelog спеки среза (правило программы 040); строка журнала ссылается на неё в ячейке «Программа / срез», не дублируя содержание.
