# GEO v0.1 — PWA-клиент (RU)

```text
Статус: Stable
Область: pwa

```

Входная точка домена `pwa`. Это **активный чертёж** клиентского (мобильного) приложения участника, а не архив.

## Статус и порядок работ

- Решение владельца 2026-10-04 (программа 028, `F-028-50`, В-10): «Планируется обязательно. Когда бекенд и ядро будет закончено и проверено — следующий этап — мобильное приложение».
- Порядок роадмапа: **бэкенд и ядро закончены и проверены → клиентское (мобильное) приложение**. Порядок записан в [`../00-overview.md`](../00-overview.md) (раздел «Порядок работ»).
- Кода клиента в репозитории сейчас нет: существуют только Admin UI (`admin-ui/`) и Simulator UI (`simulator-ui/v2/`). Реализация клиента не авторизована, пока не выполнено условие порядка выше и не заведена программа в [`../../../specs/README.md`](../../../specs/README.md).
- Чертёж привязан к контракту `api/openapi.yaml` и [`../04-api-reference.md`](../04-api-reference.md); при расхождении побеждает контракт, а чертёж правится.
