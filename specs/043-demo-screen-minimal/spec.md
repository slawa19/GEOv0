## Problem

Текущий экран (снимок 2026-10-16, `.local-run/gemini-assess/20261016-assess/repo/DEMO-SCREEN-CURRENT.png`) показывает новичку ~33 элемента управления в шести этажах: три режима с перезагрузкой страницы, тему, шесть плашек статуса, «Inspect graph» над графом, девять контролов внизу, три выпадающих меню («Advanced ⚙», «Admin ▾», «Dev Tools ▾»). Главный спотыкач — режимы: «сеть живёт» (Auto-Run) и «можно попробовать» (Interact) — разные URL с перезагрузкой, и ни один не даёт обоих сразу: `TopBar.vue:40` (Start/Pause только в auto), `SimulatorAppRoot.vue:1290` (ActionBar только в Interact), `useSimulatorApp.ts:1658-1686` (Interact принудительно ставит intensity 0), `useInteractAutoBootstrapRun.ts:50` (ран стартует `intensityPercent: 0, pauseImmediately: true`). Автостарт Auto-Run ограничен dev/localhost (`useSimulatorRealMode.ts:1398`): публичный вход без «Start» не показывает платежей. Это не денежная потеря, а потеря смысла демо — главного демо системы по решению владельца 2026-10-16.

## Решения владельца (терминальные, 2026-10-16)

1. **Первый взгляд — минимум.** Сеть живёт и занимает ≥ 85 % экрана **на первом взгляде** («Подробнее» выключено; критерий 7 программы 039 остаётся) — *поправка 2026-10-16: решение советника 2026-10-16 по запросу оркестратора: критерий 7 программы 039 писался про первый взгляд; четыре служебные строки по макету не умещаются в 115 px; значение при включённом «Подробнее» фиксируется измерением (сейчас 68.8 %), порога нет*. Одна верхняя полоса: имя сети (текст), точка состояния (текст), кнопка «Поток» (⏸/▶), три действия протокола — Send Payment, Manage Trustline, Run Clearing, — и один переключатель «Подробнее». Одна нижняя полоса: легенда (039 B1), «Общий долг» (с «было → стало» из 039 D, когда он слит), «Reset view». Одна подсказка-онбординг при первом заходе, исчезает после первого действия. Подсказка линии — словами: «А доверяет Б до X; долг Б перед А — Y; доступно Z», и при наблюдении тоже, не только в Interact.
2. **Один экран вместо трёх режимов.** Сегмент Sandbox / Auto-Run / Interact и перезагрузка страницы уходят. Открытие демо — живой настоящий прогон (если доступного нет — запускается выбранный сценарий существующим `startRun`; чужая осознанная пауза не возобновляется). Офлайн-источник (демо без сервера на снимках) — пункт «Источник» в «Подробнее». *Поправка 2026-10-16 (исполнение S2; трактовки исполнителя, на ревью оркестратора): источник по умолчанию — сервер (`apiMode` без `?mode` и без `VITE_API_MODE` теперь `real`, было `fixtures`); офлайн — «Источник» (`?mode=fixtures`) или `VITE_API_MODE=fixtures`. Смена источника — единственный оставшийся переход страницы: меняется весь конвейер данных; вход в ручное действие — ноль навигаций (репродьюсер (г)). `?ui=interact` в старых ссылках игнорируется. Demo UI (`?ui=demo`) с его перезагрузкой остаётся до S3. Автостарт — одна попытка за загрузку, когда сцена открыта: нет прогона или он закончился (`stopped`, `error`) — `startRun` с сохранённой интенсивностью (по умолчанию 30; сохранённый 0 старого Interact → 30), не на паузе; живой прогон (`running`, `paused`, `created`, `stopping`) остаётся как есть — паузу не снимаем и второй прогон рядом не ставим; статус не прочитан — не запускаем ничего. Прогон, остановленный человеком, не перезапускается за его спиной; отказ создания остаётся ошибкой на экране, повтор — Start в «Подробнее».*
3. **Ручное действие останавливает все автоматические платежи.** Дословно: «ручной режим должен останавливать все платежи! автоматические платежи, пока пользователь изучает меню и пытается что-то создать — будет отвлекать внимание». Открытие панели платежа, доверия или клиринга, либо выбор участника в потоке — ставит прогон на паузу (`pause`), точка состояния показывает «на паузе»; вернуть поток — кнопкой «Поток» (▶). Это **отменяет** прежний контракт Interact «intensity принудительно 0, local-only» (`33563ba2`): паузу вызывает действие пользователя, а не URL-режим. *Поправка 2026-10-16 (исполнение S2; трактовки исполнителя, на ревью оркестратора): поток возвращается только явным действием человека — «Поток» или Resume в управлении прогоном под «Подробнее»; подтверждение, отмена, Escape или закрытие панели поток не возобновляют никогда (результат своего действия не перекрывается автоматическими платежами) — *уточнено 2026-10-17 по внешнему ревью* (прежняя формулировка «только кнопка «Поток»» не учитывала Resume под «Подробнее», которое осталось). Пауза ставится на каждом ЯВНОМ входе или выборе (*уточнено 2026-10-17 по внешнему ревью: прежний наблюдатель одного признака «какой-то поток открыт» пропускал второй вход в том же такте, выбор участника в выпадающем списке панели и полный редактор линии*): начало потока платежа, доверия или клиринга с любого входа (панель действий, карточка участника, окно линии), выбор участника на холсте или в выпадающем списке панели (отправитель, получатель, кредитор, должник, линия из списка), «Change Limit» окна линии; очищенное поле (Escape-шаг назад) — не вход. Пауза — на акте, а не на всём протяжении действия: «Поток» при открытой панели возвращает поток, и панель его снова не останавливает. Действие, сделанное, пока прогон открытия ещё создаётся, ставит его на паузу, как только он `running`; действие до конца открытия — прогон создаётся сразу на паузе. Предел: события, которые сервер выдал до обработки `/pause`, ещё приходят. «Поток» стоит в первом ряду, только когда прогон `running` (⏸) или `paused` (▶), `aria-pressed` — включён ли поток. Подсказка-онбординг, однажды закрытая, не возвращается: второй ключ хранилища этой программы `geo.sim.v2.onboarding.dismissed` («исчезает после первого действия» — и не задаёт тот же вопрос на следующей загрузке).*
4. **Расширенный режим — один переключатель «Подробнее»**, без перезагрузки, с сохранением выбора в браузере: сверху — статусы SSE/Run/TX и TEST MODE, сценарий и его обновление, Start/Stop, темп (Intensity + Apply), тема (SaaS/HUD), Admin ▾ (при токене), полные метрики (ёмкость, линии, участники, utilization, «Capacity stall»); снизу — EQ, Layout, Labels, Quality, Источник (+ Scene в офлайне), Refresh, Analytics (правый док), Artifacts ▾, Inspect graph ▾ (навигатор по спискам — путь с клавиатуры и e2e; из плашки над графом переезжает в кнопку нижнего ряда). `?perf=1` и `?debug=1` остаются только URL-входами.
5. **Удалить совсем** (с grep-доказательствами трёх моделей): контейнер «Advanced ⚙» (после ухода Pipeline в нём одно поле); режим Demo UI (`?ui=demo`, «Enter/Exit Demo», `demoToolsAllowed`, ключи `devtools.open.*`, `fxDebugRun`) и пустую оболочку «Dev Tools ▾» — **после 042 `T4205`** (*Решение советника 2026-10-17 (по запросу оркестратора): удаление Demo UI до 042 `T4205` принято — `T4205` — клиентские плейлисты на `?mode=fixtures`, Demo UI жил только на сервере, его кнопки убраны 042 S1.*); зачистку `devtools=1` в URL (`SimulatorAppRoot.vue:90-100,693`); алиас `?mode=demo → fixtures` (`useSimulatorApp.ts:513,520`); сброс intensity «после legacy Interact» (`useSimulatorApp.ts:1658-1660`, с однократной чисткой сохранённого 0); мёртвый `@close` у `WindowShell` (`SimulatorAppRoot.vue:1323-1334`); недостижимую ветку подсказки Interact (`TopBar.vue:86-97`); проп `forceHidden` в `EdgeDetailPopup.vue:47,53,124` (`:force-hidden="false"` зашит в `SimulatorAppRoot.vue:1354`). Чего **не** удалять без нового решения: пять раскладок (вред F-034-20 не доказан), Quality, Labels, Refresh, Artifacts, Admin, два редактора линии (быстрый и полный — разные задачи одного потока), GraphNavigator.

Решения советника по расхождениям моделей (записаны в сводке; владелец видел макет с ними): выбор сценария и тема — в «Подробнее», имя сети текстом; «Recent actions» — 3 прозрачные строки над нижней полосой; кнопка «Попробовать самому» (Codex) не нужна — три действия видны сразу; `labelsLod` по умолчанию — проверить `neighbors` против `selection` на сцене 100 стендом, не словом.
