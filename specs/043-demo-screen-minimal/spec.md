Три независимых предложения по одному брифу (Codex `gpt-6-astra`, Claude Fable 5.1, Gemini Argon; read-only; сводка и расхождения — `.local-run/demo-redesign-20261016/consolidation.md`, несущие якоря повторены здесь) сошлись в главном; советник свёл, владелец одобрил.

## Problem

Текущий экран (снимок 2026-10-16, `.local-run/gemini-assess/20261016-assess/repo/DEMO-SCREEN-CURRENT.png`) показывает новичку ~33 элемента управления в шести этажах: три режима с перезагрузкой страницы, тему, шесть плашек статуса, «Inspect graph» над графом, девять контролов внизу, три выпадающих меню («Advanced ⚙», «Admin ▾», «Dev Tools ▾»). Главный спотыкач — режимы: «сеть живёт» (Auto-Run) и «можно попробовать» (Interact) — разные URL с перезагрузкой, и ни один не даёт обоих сразу: `TopBar.vue:40` (Start/Pause только в auto), `SimulatorAppRoot.vue:1290` (ActionBar только в Interact), `useSimulatorApp.ts:1658-1686` (Interact принудительно ставит intensity 0), `useInteractAutoBootstrapRun.ts:50` (ран стартует `intensityPercent: 0, pauseImmediately: true`). Автостарт Auto-Run ограничен dev/localhost (`useSimulatorRealMode.ts:1398`): публичный вход без «Start» не показывает платежей. Это не денежная потеря, а потеря смысла демо — главного демо системы по решению владельца 2026-10-16.

## Решения владельца (терминальные, 2026-10-16)

1. **Первый взгляд — минимум.** Сеть живёт и занимает ≥ 85 % экрана **на первом взгляде** («Подробнее» выключено; критерий 7 программы 039 остаётся) — *поправка 2026-10-16: решение советника 2026-10-16 по запросу оркестратора: критерий 7 программы 039 писался про первый взгляд; четыре служебные строки по макету не умещаются в 115 px; значение при включённом «Подробнее» фиксируется измерением (сейчас 68.8 %), порога нет*. Одна верхняя полоса: имя сети (текст), точка состояния (текст), кнопка «Поток» (⏸/▶), три действия протокола — Send Payment, Manage Trustline, Run Clearing, — и один переключатель «Подробнее». Одна нижняя полоса: легенда (039 B1), «Общий долг» (с «было → стало» из 039 D, когда он слит), «Reset view». Одна подсказка-онбординг при первом заходе, исчезает после первого действия. Подсказка линии — словами: «А доверяет Б до X; долг Б перед А — Y; доступно Z», и при наблюдении тоже, не только в Interact.
2. **Один экран вместо трёх режимов.** Сегмент Sandbox / Auto-Run / Interact и перезагрузка страницы уходят. Открытие демо — живой настоящий прогон (если доступного нет — запускается выбранный сценарий существующим `startRun`; чужая осознанная пауза не возобновляется). Офлайн-источник (демо без сервера на снимках) — пункт «Источник» в «Подробнее».
3. **Ручное действие останавливает все автоматические платежи.** Дословно: «ручной режим должен останавливать все платежи! автоматические платежи, пока пользователь изучает меню и пытается что-то создать — будет отвлекать внимание». Открытие панели платежа, доверия или клиринга, либо выбор участника в потоке — ставит прогон на паузу (`pause`), точка состояния показывает «на паузе»; вернуть поток — кнопкой «Поток» (▶). Это **отменяет** прежний контракт Interact «intensity принудительно 0, local-only» (`33563ba2`): паузу вызывает действие пользователя, а не URL-режим.
4. **Расширенный режим — один переключатель «Подробнее»**, без перезагрузки, с сохранением выбора в браузере: сверху — статусы SSE/Run/TX и TEST MODE, сценарий и его обновление, Start/Stop, темп (Intensity + Apply), тема (SaaS/HUD), Admin ▾ (при токене), полные метрики (ёмкость, линии, участники, utilization, «Capacity stall»); снизу — EQ, Layout, Labels, Quality, Источник (+ Scene в офлайне), Refresh, Analytics (правый док), Artifacts ▾, Inspect graph ▾ (навигатор по спискам — путь с клавиатуры и e2e; из плашки над графом переезжает в кнопку нижнего ряда). `?perf=1` и `?debug=1` остаются только URL-входами.
5. **Удалить совсем** (с grep-доказательствами трёх моделей): контейнер «Advanced ⚙» (после ухода Pipeline в нём одно поле); режим Demo UI (`?ui=demo`, «Enter/Exit Demo», `demoToolsAllowed`, ключи `devtools.open.*`, `fxDebugRun`) и пустую оболочку «Dev Tools ▾» — **после 042 `T4205`**; зачистку `devtools=1` в URL (`SimulatorAppRoot.vue:90-100,693`); алиас `?mode=demo → fixtures` (`useSimulatorApp.ts:513,520`); сброс intensity «после legacy Interact» (`useSimulatorApp.ts:1658-1660`, с однократной чисткой сохранённого 0); мёртвый `@close` у `WindowShell` (`SimulatorAppRoot.vue:1323-1334`); недостижимую ветку подсказки Interact (`TopBar.vue:86-97`); проп `forceHidden` в `EdgeDetailPopup.vue:47,53,124` (`:force-hidden="false"` зашит в `SimulatorAppRoot.vue:1354`). Чего **не** удалять без нового решения: пять раскладок (вред F-034-20 не доказан), Quality, Labels, Refresh, Artifacts, Admin, два редактора линии (быстрый и полный — разные задачи одного потока), GraphNavigator.

Решения советника по расхождениям моделей (записаны в сводке; владелец видел макет с ними): выбор сценария и тема — в «Подробнее», имя сети текстом; «Recent actions» — 3 прозрачные строки над нижней полосой; кнопка «Попробовать самому» (Codex) не нужна — три действия видны сразу; `labelsLod` по умолчанию — проверить `neighbors` против `selection` на сцене 100 стендом, не словом.
