## Метод среза

1. **Заморозка.** Все ревью идут на `main` `66f29397` из standalone credential-free clone `.local-run/codex-review/054-<блок>-20261030/clone` (runbook §1.1, §3). Промпт замораживается отдельно и записывается рядом.
2. **Два независимых ревьюера на срез**, оба read-only, оба получают один и тот же перечень форм дефекта из таблицы, а не просьбу «оценить качество» (AGENTS §15): Claude Opus (агент без edit/write) и Codex `gpt-6-astra` (`codex exec --sandbox read-only -m gpt-6-astra -c model_reasoning_effort=high -o final.md`; requested model записывается, resolved не подтверждается). Timeout/обрыв/пустой `-o` = `UNVERIFIED`, не «0 находок»; один записанный fallback (GitHub-коннектор на точном SHA).
3. **Сведение** нижним оркестратором: таблица «находка → кто назвал → воспроизведено ли → класс §19.5 → затронутые call-sites/соседние части». Каждый P1/P2 воспроизводится **runtime-witness** на реальном пути (локальный тест в detached worktree `.local-run/worktrees/054-<блок>-witness/`, не tracked, canonical runner с `-TaskSlug p054_<блок>_<n>`), как OMR 2026-10-29. Не воспроизведённое записывается кандидатом, не находкой.
4. **Главная сессия** проверяет несущие факты (`path:line`, репродьюсер), вносит принятое в `## Findings`, назначает приоритет реализации с учётом влияния на другие части (общие вызывающие, контракты §8, тесты соседних программ) и owner surface правки.
5. **Исправления** — отдельными волнами по блокам после классификации: класс 1 чинится узко до закрытия; класс 2 с дешёвой общей правкой — в волну блока; остальное — `specs/BACKLOG.md`. Внешнее ревью fix-delta — Codex (оркестратор — Claude Code), триггеры §15.
