## Problem

Публичная демка (044) показывает посетителю, впервые видящему GEO, элементы трёх разных адресатов вперемешку: зрительские (сеть, действия, легенда), административные (сценарий, темп, прогоны, файлы) и отладочные (источник, качество рендера, SSE, TEST MODE, плейлист). Часть видимого — дубли одного состояния, часть — мёртвые контролы, часть — советы, которые сервер выдаёт по сломанной формуле и которые не ведут ни к одному действию. Ошибки показываются девятью разными формами, с «Error», «HTTP 500» и идентификатором запроса крупным шрифтом, а тост гасит ошибку в открытом окне раньше, чем её прочтут. Слово владельца — в Status.

## Findings (проверены советником по `main` `9c729faf`; кто назвал — в скобках)

- **F-048-1 — советы аналитики не выполнимы и не достоверны** (все три). Из шести кодов контракта сервер пишет два: `TOO_MANY_TIMEOUTS`, `FREQUENT_ABORTS`; ветка `HIGH_USED` (`storage.py:491`) недостижима — требует `errors == 0`, а при `bad == 0` цикл уже вышел (`:480`) (Gemini; Codex и Fable считали код живым — посылка исправлена); `LOW_AVAILABLE`, `ROUTING_TOO_DEEP`, `CLEARING_PRESSURE` писателя не имеют (`git grep -n ROUTING_TOO_DEEP -- app/core` → только схема); снимок владельца с тремя кодами — тестовая фикстура (`e2e/p046-w2-windows-ru.spec.ts:70`). ## Решения (советник по поручению владельца, 2026-10-18)

1. **Аналитика — админу, диагноз без советов и без процента.** Кнопка Analytics и правый док не показываются без админского токена (условие `showAdminControls`, `TopBar.vue:225`); в доке остаются четыре ряда (успешные платежи, объём клиринга, средняя длина маршрута, индекс узких мест) и список узких мест в виде «на линии A → B зафиксированы отказы платежей» / «часто истекало время ожидания» — без строки совета (`reasonAction`, `bottlenecks.action.*`) и без процента, пока формула на сервере не починена (BACKLOG 048-1). `Focus` открывает окно линии через существующий путь навигатора (`inspectEdgeFromNavigator`), действия — в окне. Контракт сервера (`BottleneckReasonCode`, `score`, `label`, `suggested_action`) не меняется (§8). **Поправка к 043 реш. 4** («Analytics (правый док)» в «Подробнее» для всех → для админа). Полное удаление отвергнуто: ряды нужны тому, кто показывает демо, работа 007 не выбрасывается.
2. **Плашка Stall — на первый взгляд, словами с действием.** Показывается без «Подробнее», текст из словаря: RU «Платежи не проходят: лимиты исчерпаны — проведите клиринг или увеличьте лимит», EN «Payments are not going through: limits are exhausted — run clearing or raise a limit». Механизм прежний (`consec_all_rejected_ticks ≥ STALL_THRESHOLD_TICKS`); текст не утверждает причину сильнее механизма. **Поправка к 043 реш. 4** (Stall был под «Подробнее»).
3. **Одна форма ошибки зрителя.** Одно предложение «что случилось → что сделать» на языке интерфейса, в месте действия: для окон — встроенный блок окна, для прогона — верхняя плашка; слова «Error», «HTTP <код>», «Reference», имя класса исключения на экран не выводятся (HTTP-статус — в `title` и консоль); идентификатор — отдельной второй строкой приглушённо «код запроса: <id>» / «request id: <id>» и в `data-request-id` (§12 соблюдён; `withRequestRef` возвращает `{text, ref}` вместо склейки). Тост для ошибок окон снимается (дубль + гашение); компонент `ErrorToast` остаётся, если у него есть другой потребитель — проверить при реализации. Новых кнопок «Повторить» не вводится: 409 получает повтор в 044, окна имеют отмену/закрыть, аналитика — админская («данные сейчас недоступны — попробуйте позже»). Полноэкранная ошибка сцены и верхняя плашка — одно место, не два (verify first). Различие «нет данных / пусто / ошибка сервера / подтверждённый отказ / результат неизвестен» сохраняется (блок неизвестного исхода `ManualPaymentPanel.vue:864` не трогается).
4. **Удалить:** бейдж `Run <state>` и `runTone`; Pause/Resume служебного ряда с их обработчиками (события `pause`/`resume` и «Поток» остаются); бейдж TEST MODE (флаг `isTestMode` остаётся — он влияет на стенд); плашка Clean и поле `isClean` после неё (проверки замороженного долга — на `totalUsed`); селектор Scene вместе с `scenes.ts`, параметром `?scene=` и полем `scene` (единственный читатель — селектор); кнопка Refresh снимка (`refreshSnapshot` остаётся конвейеру восстановления); строка `Status` подсказки линии; статичная ветка `EQ UAH` при `isDemoFixtures` (эквивалент показывается текстом, когда вариант один, селектором — когда больше; флаг `VITE_DEMO_FIXTURES` не трогается); ряды `total_debt`/`active_participants`/`active_trustlines` из `SERIES_ORDER` (тип `MetricSeriesKey` остаётся полным). **Уточнение 043 реш. 3:** оговорка «Resume в управлении прогоном под «Подробнее»» снимается вместе с кнопкой; поток возвращает только «Поток».
5. **Перенести:** Artifacts → Admin ▾ как «Файлы прогона» (ноль не показывать до загрузки индекса — «не загружено» ≠ «нет файлов»); ↻ каталога сценариев → Admin ▾ (нужен после загрузки сценария админом); Источник (и Scene-офлайн нет — удалён), Quality, бейдж SSE, Плейлист → только при `?debug=1`; плейлист — при `?debug=1` **и** офлайн-источнике (как сейчас по источнику). `?debug=1` получает читателя (`useSimulatorApp`), и смена источника **переносит** его в новый URL (`SimulatorAppRoot.vue:919` — удаление снимается); `scripts/run_simulator_ui.ps1 -Mode fixtures` открывает `?mode=fixtures&debug=1`, чтобы 039 C не потерял измерительный стенд. Потеря связи SSE — в текст состояния сети («нет связи с сервером»), сырой бейдж — `?debug=1`. **Поправка к 043 реш. 2** («офлайн-источник — пункт «Источник» в «Подробнее»» → в `?debug=1`); реш. 5 не нарушено: Layout и Quality не удаляются.
6. **Оставить зрителю в «Подробнее»:** сценарий, Старт/Стоп, темп + Применить, тема, язык (046 W1), метрики сети (доступно для платежей, линии, участники, занято лимитов), «Платежи: a из b прошли» (при `attempts = 0` — «Платежей ещё не было», не «0 %»), причина остановки словами (044 закрытый набор `stop_reason`), эквивалент, раскладка, подписи, «Найти на графе». Посетитель по-прежнему может менять темп и останавливать **свой** прогон — это право сервера (`simulator.py:2944`), не UI; перенос Stop под Admin отвергнут.
7. **Слова — только через словарь 046** (таблица §G ниже — вход волны 1 и волны 3). 048 текстов не правит.
