## Problem

Публичное демо показывает два языка в одной строке. Механизма выбора языка нет: `uiLocale()` читает `<html lang>` и используется только параметром по умолчанию в текстах отказов; компоненты его не зовут. Шесть тестов выставляют `document.documentElement.lang` руками, unit-тесты идут с пустым `lang` (английский), Playwright — с `lang="ru"`: один и тот же текст проверяется в разных языках в разных тирах. Строки с сервера (`last_error` как `${code}: ${message}`, `stop_reason`, `label`/`suggested_action` узких мест — английская проза) выводятся как есть. Потеря — читаемость демо для зрителя, который ждёт одного языка; денежной потери нет.

## Решения

1. **Два полных языка, один словарь.** `src/i18n/en.ts` и `src/i18n/ru.ts`, вложенные по областям экрана; `ru` типизирован ключами `en` (`satisfies Record<MessageKey, string>`, образец `MetricsKpiCard.vue:14-24`). `interactStrings.ts` (61 ключ) и карты `REASONS` поглощаются — одного словаря требуют 034/037. Подстановки — именованные плейсхолдеры `{amount} {unit}`, число и единица раздельно; множественное число — `Intl.PluralRules` по категориям (`one/few/many/other` для ru); целые предложения, не склейка фрагментов (подсказка линии — шаблон целиком).
2. **Выбор языка — один модуль, один писатель `<html lang>`.** Приоритет: `?lang=` → сохранённый `geo.sim.v2.lang` → `navigator.languages` (`ru`/`uk`/`be` → ru, иначе en) → `en`. Ссылка не пишет в хранилище (как у темы); `replaceState` без перезагрузки; `uiLocale()` становится читателем модуля (шесть тестов продолжают работать). **Переключатель — под «Подробнее»** (служебный ряд), не на первом взгляде: инвариант 043 «≤ 7 остановок» сохраняется, язык для зрителя выбирается автоматически по браузеру, а публичная ссылка может нести `?lang=`. (Решение советника 2026-10-18; владелец может перенести переключатель на первый взгляд — тогда датированная поправка инварианта 043 до ≤ 8.)
3. **Строки с сервера переводятся по закрытым множествам кодов на клиенте:** отказы платежа/клиринга (уже RU/EN), состояние прогона, `stop_reason` (карта терпит неизвестное значение: показывает код), `reason_code` узких мест (6 значений, `simulatorContracts.ts:908-915`) вместо английской прозы `label`/`suggested_action`, статусы рёбер/узлов/платежей. `last_error` неизвестного кода — общий текст на языке интерфейса + сам код для корреляции (§12). Сервер не меняется.
4. **Деньги и имена не переводятся.** Суммы — десятичные строки с точкой в обоих языках; ввод с запятой не принимается молча (подсказка на языке интерфейса); коды эквивалентов без перевода; `localeCompare` без локали в `useParticipantsList.ts:33` — оставить (или `'en'`, порядок стабилен). Названия сценариев и участников — данные.
5. **Тесты.** Первая волна миграции сохраняет английские строки байт в байт — реальных правок только 14 файлов с русскими утверждениями и два селектора по `aria-label`. Дальше тесты утверждают текст через словарь (`t('key')`) либо явно на одном языке с выставленной локалью. **Гард паритета словаря** (именованный policy-гард, §11): ключи `ru` = ключи `en`; в `en` нет кириллицы; в `ru` нет значений только из латиницы, кроме кодов/имён из явного списка; плейсхолдеры совпадают по ключу. Контрпроверка — мутация (убрать ключ из `ru`) гард роняет.
6. **Ширина.** Русский длиннее на 20–35 %: рельса подписей 72 px (045) не вмещает «Отправитель/Получатель» — подписи формы в ru короткие («От кого», «Кому», «Сумма»); меряются пробами 045/one-screen в ru: ни один контрол не переполняется и не выходит за окно; служебный ряд TopBar в ru — тем же тестом `top-bar-long.qa.ts`.
7. **Документы** (`hud-user-guide.md`, `visual-language.md`: «легенда — English») — в последней волне, с заменой «язык интерфейса — English» на «язык по браузеру/переключателю».

- Не делать переключатель на первом взгляде без решения владельца (инвариант 043).
